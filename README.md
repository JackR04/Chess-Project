# Chess-Project
A chess project created as a university assignment in Unity C#

SCR_AbilityButton = Linking UI buttons with peice base script where abilities are defined
SCR_KillParticles = Kills particles spawned from abilities
SCR_VideoSwitch = swithes to idle video when on main menu and no input detected for 30 seconds
SCR_Peice_Base = Only includes the functions i created to control abilities for each peice
